# Trafic_light_verilog_Gowin
A traffic light controller implemented in SystemVerilog on the Tang Nano 4K FPGA board, featuring FSM-based control, timed state transitions, and external LED control.

## Описание проекта
В данном проекте реализован контроллер светофора на языке SystemVerilog с использованием FPGA-платы Tang Nano 4K. В основе контроллера лежит конечный автомат (FSM), обеспечивающий последовательное переключение трёх внешних светодиодов в соответствии с заданными временными интервалами.

Основной целью проекта является получение практического опыта RTL-проектирования, реализации конечных автоматов, синтеза цифровых схем, работы со средой разработки Gowin EDA и аппаратной отладки на ПЛИС.

## Архитектура контроллера
Архитектура контроллера состоит из трёх основных функциональных блоков:
* Конечный автомат (FSM) — отвечает за хранение текущего состояния светофора и переход между состояниями.
* Счётчик тактов — обеспечивает формирование необходимых временных интервалов путём подсчёта импульсов тактового сигнала.
* Комбинационная логика управления выходами — формирует сигналы включения светодиодов в зависимости от текущего состояния конечного автомата.
Последовательная логика реализована с использованием блока always_ff, а комбинационная логика управления выходными сигналами реализована с использованием блока always_comb.

Все функциональные блоки реализованы внутри одного RTL-модуля.

## Реализация счётчика тактов

Для формирования временных интервалов используется тактовый генератор
платы Tang Nano 4K с частотой 27 МГц.

Количество необходимых тактов рассчитывается по формуле:

**N = fₖₗₖ × T**

где:

- N — количество тактов;
- fₖₗₖ — частота тактового сигнала;
- T — длительность состояния.

### Расчёт количества тактов

Для красного и зелёного сигналов:

**N = 27 × 10⁶ × 5 = 135 000 000**

Для жёлтого сигнала:

**N = 27 × 10⁶ × 2 = 54 000 000**

### Расчёт разрядности счётчика

Необходимая разрядность счётчика определяется по формуле:

**W = ⌈log₂(Nₘₐₓ)⌉**

Поскольку:

- 2²⁷ = 134 217 728
- 2²⁸ = 268 435 456

**2²⁷ < 135 000 000 < 2²⁸**

Следовательно, необходимая разрядность счётчика составляет 28 бит.

```systemverilog
logic [27:0] tacts;
```

При достижении значения N − 1 счётчик обнуляется,
а конечный автомат переходит в следующее состояние.
## Аппаратная реализация 
Для аппаратной реализации проекта использовалась FPGA-плата Tang Nano 4K. Подключение внешних светодиодов осуществлялось с помощью макетной платы, соединительных проводов и токоограничивающих резисторов.

Каждый светодиод подключён к отдельному выходу ПЛИС через резистор сопротивлением 220 Ом. Все светодиоды имеют общую землю, соединённую с выводом GND платы.

### Используемые компоненты
* FPGA-плата Tang Nano 4K.
* Красный светодиод.
* Жёлтый светодиод.
* Зелёный светодиод.
* Три резистора сопротивлением 220 Ом.
* Макетная плата.
* Соединительные провода.
* USB-кабель.

## Синтез и программирование ПЛИС
Разработка и аппаратная реализация проекта осуществлялись в среде Gowin EDA.

В процессе разработки были выполнены следующие этапы:
1. Разработка RTL-модуля на языке SystemVerilog.
2. Назначение физических выводов ПЛИС.
3. Задание временных ограничений для тактового сигнала.
4. Синтез цифровой схемы (Synthesis).
5. Размещение и трассировка (Place & Route).
6. Формирование конфигурационного файла .fs.
7. Загрузка конфигурации в SRAM ПЛИС с помощью Gowin Programmer.
8. Проверка работоспособности устройства на реальной плате.

## Демонстрация работы

В результате аппаратного тестирования была подтверждена работоспособность контроллера светофора. Устройство обеспечивает последовательное переключение светодиодов в соответствии с заданными временными интервалами.
